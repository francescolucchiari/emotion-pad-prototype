# Emotion pad · prototipo

Prototipo interattivo di un pad bidimensionale (sensazione × energia) per il tracciamento emotivo.

Aprilo da telefono: https://francescolucchiari.github.io/emotion-pad-prototype/

Su Android (Chrome) il pad vibra a ogni scatto sulla griglia, al cambio di area e al rilascio. Su iOS il web non può attivare la vibrazione: resta il clic sonoro.
